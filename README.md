# 🧮 Professional Calculator App

A full-stack calculator application with modern UI, scientific functions, and database history.

## 🚀 Features

- **Basic Operations**: Add, Subtract, Multiply, Divide
- **Scientific Functions**: Square root, Power, Factorial, Sin, Cos, Tan, Log, Ln, Pi, e
- **Dark/Light Theme**: Toggle between themes
- **Sound Effects**: Button click sounds
- **History**: All calculations saved in SQL Server
- **Search**: Filter calculations by text
- **Favorites**: Star important calculations
- **Export CSV**: Download history
- **Statistics**: Total, Today, Favorites count
- **Keyboard Support**: Full keyboard shortcuts
- **Mobile Responsive**: Works on all devices

## 🛠️ Tech Stack

### Backend
- Java 17
- Spring Boot 3.2.5
- Spring Data JPA
- Hibernate
- Microsoft SQL Server
- Maven

### Frontend
- HTML5
- CSS3 (Modern gradient design)
- Vanilla JavaScript (ES6+)
- Fetch API

### Database
- Microsoft SQL Server (MSSQL)
- Calculation history table
